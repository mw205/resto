# **١. نظرة عامة على المشروع**

بناء تطبيق موبايل متكامل لمطعم متنوع يتيح للعملاء تصفح المنيو، تقديم الطلبات، ومتابعة حالتها لحظة بلحظة — سواء توصيل لباب البيت أو استلام من الفرع (Takeaway).

يشمل المشروع ثلاثة مكونات رئيسية:

* تطبيق موبايل للعميل (Android \+ iOS) مبني بـ Flutter

* لوحة تحكم ويب (Dashboard) مبنية بـ React.js تخدم الأدمن والديليفري

* Backend API مبني بـ .NET (ASP.NET Core) مع SQL Server

# **٢. أنواع المستخدمين**

## **٢.١ العميل (Customer)**

يصل إلى النظام عبر تطبيق الموبايل فقط.

* تصفح المنيو وإضافة أصناف للسلة

* تقديم الطلب واختيار طريقة الاستلام (Delivery أو Takeaway)

* تتبع حالة الطلب لحظياً مع Push Notifications

* استخدام الكوبونات والخصومات

* إرسال الشكاوى والاقتراحات وتقييم الطلب

* عرض سجل الطلبات السابقة وإعادة الطلب

## **٢.٢ الأدمن (Admin)**

يصل إلى النظام عبر لوحة التحكم (Web Dashboard).

* إدارة كاملة للمنيو: إضافة / تعديل / حذف الأصناف والفئات

* رفع صور المنتجات وتحديد السعر والتوفر

* استقبال الطلبات الجديدة وتغيير حالتها يدوياً

* تعيين موظف ديليفري لكل طلب

* إنشاء وإدارة الكوبونات والخصومات

* مراجعة الشكاوى والرد عليها

* عرض تقارير المبيعات اليومية والشهرية

* إدارة حسابات المستخدمين وأدوارهم

## **٢.٣ الديليفري (Driver)**

يصل إلى النظام عبر نفس لوحة التحكم (Web Dashboard) بصلاحيات محدودة.

* عرض الطلبات المعينة له فقط

* تغيير حالة الطلب (في الطريق / تم التسليم)

* عرض بيانات العميل وعنوانه

# **٤. ميزات تطبيق الموبايل (العميل)**

## **٤.١ المنيو الديناميكي**

* تصفح الأصناف مقسمة بالفئات (مشويات، مأكولات بحرية، حلويات...)

* كل صنف يحتوي على صورة، وصف، وسعر

* بحث وفلترة حسب الفئة

* الأصناف المتوفرة والمنتهية تُحدَّث لحظياً من الأدمن

## **٤.٢ السلة والطلب**

* إضافة أصناف بكميات مختلفة مع ملاحظات خاصة (مثال: بدون بصل)

* تطبيق كود كوبون الخصم قبل التأكيد

* اختيار طريقة الاستلام: Delivery (مع إدخال العنوان) أو Takeaway

* تأكيد الطلب والدفع كاش عند الاستلام

## **٤.٣ تتبع الطلب (Order Tracking)**

شاشة تتبع تفاعلية تُظهر حالة الطلب خطوة بخطوة مع إشعارات Push Notifications عند كل تغيير.

**مراحل الـ Delivery:**

* تم استلام الطلب

* قيد التحضير

* في الطريق (يغيرها موظف الديليفري)

* تم التسليم

**مراحل الـ Takeaway:**

* تم استلام الطلب

* قيد التحضير

* جاهز للاستلام

## **٤.٤ الكوبونات والخصومات**

* إدخال كود الكوبون في شاشة السلة

* حساب الخصم تلقائياً (نسبة مئوية أو مبلغ ثابت)

* الأدمن ينشئ الكوبونات من الداشبورد بتاريخ انتهاء وحد أقصى للاستخدام

## **٤.٥ الشكاوى والتقييم**

* تقييم الطلب بعد التسليم (نجوم \+ تعليق نصي)

* إرسال شكوى أو اقتراح في أي وقت

* الأدمن يرى كل الشكاوى ويرد عليها من الداشبورد

## **٤.٦ سجل الطلبات**

* عرض كل الطلبات السابقة مع حالتها وتفاصيلها

* إعادة الطلب بنقرة واحدة (Reorder)
