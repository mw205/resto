# Resto Web Landing Page (`resto_landing_page`)

The official marketing and promotional landing page for **Resto (ريستو)**, inviting visitors to download the mobile application and explore Egyptian gastronomy.

---

## How to Run the Landing Page

```bash
cd packages/resto_landing_page

# Launch in Chrome
flutter run -d chrome
```

---

## Key Features

1. **Hero Section:**
   - High-impact Egyptian Arabic headline highlighting grilled meats and traditional tagines.
   - Direct call-to-action badges for **App Store** and **Google Play**.
   - Photorealistic 3D smartphone mockup showcasing `resto_app` displaying live menu items, prices in EGP, and ratings.

2. **Why Resto (Value Proposition):**
   - Charcoal-grilled authentic Egyptian meats.
   - Real-time GPS order tracking with captains.
   - Premium thermal insulated packaging.
   - Flexible payment options (Cash on delivery & online payment).

3. **Featured Dishes Showcase:**
   - Visual cards highlighting popular dishes: Kebab & Kofta, Okra Lamb Tagine, Stuffed Pigeon with Grits.

4. **Captain Recruitment Banner:**
   - Call to action inviting motorcycle and scooter owners to join the Resto delivery fleet.

5. **Direct Admin Access Button:**
   - Header button providing seamless navigation to the Admin Web Operations Dashboard.
